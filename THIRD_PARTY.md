# Third-party assets

## Michroma

GIBSON includes the Michroma font by the Michroma Project Authors.

The font uses the SIL Open Font License 1.1. Read `assets/fonts/OFL.txt` for the full licence.

## Official release soundscape

Official binaries include compressed effects from the Mixkit free sound-effects library.

Mixkit distributes these effects under its Sound Effects Free License:

https://mixkit.co/license/#sfxFree

The sound files are embedded in the application. They are not available as separate stock files.

The official soundscape uses these Mixkit items:

- Fast sweeping transition 164.
- Flying fast swoosh 1469.
- Sci-fi rocket engine 1723.
- Sci-fi sweep 2522.
- Synth suspense music 681.
- Transition flying swoosh 3161.

The public source build uses original synthesised fallback sounds. These fallback sounds use the project MIT licence.
