# Security policy

GIBSON displays file names and terminal content. Do not include private content in a public report.

Report a security problem through a [private GitHub security advisory](https://github.com/Popidge/gibson-ui/security/advisories/new).

Include the GIBSON version, Arch package versions, and clear reproduction steps. Remove private paths and terminal output first.

Security fixes target the current release. Older releases do not receive separate support.
